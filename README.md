# Go MaxYMiser

A Go implementation of the MaxYMiser YM2149 tracker by Gareth Morris / gwEm.
The original tracker combines three YM channels, instrument sequences and
Atari STe sample tracks. This project uses YM Player for YM2149 synthesis.

Original design credits: Gareth Morris / gwEm and Mathieu Stempell / Dma-Sc.
Original graphics: Sebastien Larnac / STSurvivor.
